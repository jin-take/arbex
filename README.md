# arbex

Arbitrage × Execution

Goの取引エンジン、Next.jsの監視UI、Solidityの実行コントラクトで構築するDEXアービトラージシステムです。

現在は概要設計を議論する段階です。アプリケーション・実売買はまだ実装していません。
